# Technology logos

The "Tools you will use" section on the homepage shows a logo for each technology
when a file with the matching name exists in this folder, and a neutral monogram
tile when it does not. Nothing else needs to change: add the file and reload.

Use the official logo files from each vendor's brand or press page, and follow
that vendor's usage rules. SVG files are best. Square or near-square versions
look best in the 26 px slot.

Expected file names:

aws.svg, azure.svg, googlecloud.svg, docker.svg, kubernetes.svg, helm.svg,
terraform.svg, ansible.svg, githubactions.svg, gitlab.svg, jenkins.svg,
argocd.svg, prometheus.svg, grafana.svg, linux.svg, git.svg, bash.svg, python.svg
